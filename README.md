#大鱼吃小鱼

一款 2D 休闲吞食小游戏：控制你的鱼吃掉比自己小的鱼不断变大，同时躲避更大的鱼。

## 玩法
- 吃掉小鱼变强，被大鱼咬到会掉一条命（共 3 条），连续吃鱼可叠连击
- 单人模式：WASD / 方向键移动，空格冲刺
- 双人模式：P1 用 WASD + 空格，P2 用方向键 + Enter，合作计分

## 特点
- Q版卡通矢量海洋风格，明亮清新，光影柔和
- 8 种鱼可选形象，各有特色
- 海底分层景深、海草珊瑚、上浮气泡、拖尾与泡泡粒子特效
- 纯单文件 HTML，零依赖，打开即玩
