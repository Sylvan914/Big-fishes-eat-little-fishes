# 开局捏鱼，吞遍深海 · 抖音小游戏工程

这是由原浏览器版 HTML5 单文件游戏《大鱼吃小鱼》改造而来的**抖音小游戏标准工程**。游戏内核（对局逻辑 / Canvas 渲染 / 吞噬碰撞 / 分数计算 / 主页 / DIY 捏鱼 / 起名 / 背包碎片 / 鱼种图鉴 / VIP 稀有鱼 / 本地存档）**全部保留原逻辑**，仅做平台适配与性能优化。

## 工程结构（完整文件树）

```
minigame/
├── game.json                    # 小游戏全局配置（竖屏、隐藏状态栏、网络超时）
├── project.config.json          # 工程配置（AppID 填写处在这里）
├── game.js                      # 入口：先加载 adapter.js 再加载 main.js
├── js/
│   ├── adapter.js               # tt 环境 → 浏览器 API 兼容层（window/document/canvas/localStorage/RAF）
│   └── main.js                  # 游戏内核 + Canvas UI + 触屏输入（全部业务逻辑）
└── cloudfunctions/
    └── save/                    # 云函数：玩家存档云端读写（云端 + 本地双缓存）
        ├── index.js
        └── package.json
```

> 根目录的 `index.html` 为原始浏览器版源码，保留作为参考，**不需要**放进小游戏工程（小游戏是纯 Canvas，无 DOM/CSS）。

## 一、拿到代码后怎么导入抖音开发者工具

### 第 1 步：注册 / 认证 / 创建小游戏，拿到 AppID

1. 打开抖音开放平台 <https://developer.open-douyin.com>，用抖音 App 扫码登录。
2. 若未认证：进入「个人中心」→「开发者认证」，完成**个人开发者认证**（实名 + 身份信息，一般即时或数小时内通过）。
3. 认证通过后，在控制台「应用 / 小游戏」→「创建小游戏」，填写名称（如「开局捏鱼吞遍深海」）、类目，提交。
4. 创建成功后，在「小游戏详情」页拿到 **AppID**（形如 `tt` 开头的一串字符）。

> 你已注册抖音开发者平台，可直接从「创建小游戏」开始。

### 第 2 步：下载抖音开发者工具

- 抖音开发者工具下载页：<https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/developer-tools>（选择对应系统版本安装）。

### 第 3 步：导入工程 + 填写 AppID

1. 打开抖音开发者工具 → 「导入项目」。
2. 项目目录选择本 `minigame` 文件夹。
3. **AppID 填写位置**：
   - 在导入弹窗的 AppID 输入框中填入你的真实 AppID；或
   - 直接编辑 `minigame/project.config.json` 里的 `"appid"` 字段，把 `"tt_此处填写你的AppID"` 替换为真实 AppID（去掉 `tt_` 前缀，直接填 AppID 本身）。
4. 点击「确定」，工具会自动编译。

### 第 4 步：真机扫码预览 + 测试全部功能

1. 工具顶部点击「预览」，会生成二维码。
2. 用抖音 App 扫码，在真机上打开小游戏。
3. 逐项测试：
   - 主页大厅（左角色待机游动 + 右开始按钮 + 顶部图标 + 底部信息栏）
   - 捏鱼 DIY / 起名 / 背包碎片 / 鱼种图鉴 / VIP 稀有鱼（碎片 + Lv 解锁）
   - 对局吞噬、分数、冲刺、暂停、结算
   - 切后台（隐藏）再回来，确认本地存档不丢
4. 真机上重点观察**帧率是否流畅**（本工程已内置 FPS 自动降档优化）。

### 第 5 步：上传版本、提交审核、备案

1. 工具内「上传」版本包，填写版本号与备注。
2. 在开放平台控制台提交审核，选择类目与素材（图标、截图、简介）。
3. **备案**：按平台要求完成小程序 / 小游戏备案（信息核对 + 提交），备案通过后才能正式发布。
4. 审核通过后「发布」，即可在抖音内搜索 / 扫码游玩。

## 二、上线审核常见驳回风险点提示

1. **类目与资质不符**：游戏类小游戏需选择「游戏」相关类目，个人开发者部分游戏类目可能受限，需提前确认个人主体能否上架游戏类目。
2. **名称 / 简介违规**：名称避免使用「最」「第一」「唯一」「正版」等绝对化用语，简介不要夸大或含诱导。
3. **素材侵权**：图标、截图、美术素材避免使用他人版权形象（动漫 IP、商标、明星形象等）。
4. **诱导分享 / 强制互动**：不要设置「分享后才能玩」「转发解锁」等强制分享逻辑。
5. **广告 / 支付违规**：本工程**未接入任何支付与广告代码**（仅留注释占位）。若后续接入广告，需遵守平台广告规范，禁止诱导点击、遮挡误触。
6. **隐私合规**：如需采集用户信息（如昵称、头像）需有明确告知；本工程昵称仅存本地 + 云端，不涉及敏感信息。
7. **备案未完成**：正式发布前务必完成平台备案，未备案会被驳回或限制发布。
8. **真机功能异常 / 崩溃**：审核会用真机跑关键路径，提交前务必在真机完整测试一遍，避免白屏、闪退、存档丢失。

## 三、云端存档说明（可选）

- 本工程采用 **本地（tt 存储）+ 云端（云函数）双缓存**。本地存档开箱即用；云端存档需额外部署：
  1. 在抖音云控制台创建云函数 `save`，上传 `minigame/cloudfunctions/save/` 目录。
  2. 云数据库创建集合 `player_saves`，权限设为「仅创建者可读写」。
  3. `index.js` 内 SDK 包名以抖音云实际环境为准（默认 `wx-server-sdk`，抖音云通常兼容，按控制台指引替换即可）。
- 不部署云端也能正常游玩，仅缺少跨设备同步能力。
