# 真机测试清单（上线前逐项过一遍）

> 用抖音 App 扫码「预览」在真机上测。重点：白屏 / 闪退 / 存档丢失 / 掉帧，这四类最容易被审核驳回。
> 建议至少覆盖一台**低端安卓机**（千元机）验证性能。

## 1. 首次进入 · 协议弹窗
- [ ] 首次打开弹出「用户协议与隐私政策」弹窗，文案可上下滑动查看。
- [ ] 点「不同意」→ 弹出提示「需同意协议后才能进入游戏」，停留在弹窗。
- [ ] 点「同意并继续」→ 进入主页。
- [ ] 杀掉小程序重新打开 → **不再**弹协议（已记录同意）。
- [ ] 清除小程序缓存后重新打开 → 重新弹出协议。

## 2. 主页大厅
- [ ] 深海海报背景正常（丁达尔光束 + 浮游光点 + 水母 + 小鱼群），无白屏/黑屏。
- [ ] 左列角色待机游动（30fps 流畅，不卡顿）。
- [ ] 昵称 / Lv·称号 / 累计吞噬 / 出战鱼名 / 碎片进度 显示正确。
- [ ] 顶部 6 图标（背包/图鉴/DIY/VIP/任务/邮件）点击跳转正确，可返回。
- [ ] 右侧「开始游戏」按钮 → 进入菜单（单人/双人）。
- [ ] VIP/任务/邮件 三个占位弹窗（金框「敬请期待」）可正常打开、返回。

## 3. 捏鱼 DIY / 起名 / 背包 / 图鉴
- [ ] DIY：换体型/配色/鱼鳍/尾巴/眼睛/花纹，保存并装备后主页角色同步更新。
- [ ] 起名：中文/英文昵称输入正常（`tt.showKeyboard`），保存后主页昵称刷新。
- [ ] 背包：碎片数量、进度条、VIP 鱼「还差 N 片 · 需 Lv X」显示正确。
- [ ] 图鉴：6 款 VIP 鱼锁定态为黑影+「封」角标；解锁后为完整高亮外观。
- [ ] 选鱼：普通鱼 + VIP 鱼都能选中进入对局。

## 4. 对局（核心）
- [ ] 对局背景为多层视差深海（光束/礁石/鱼群/水母/气泡），中间区域干净不挡鱼。
- [ ] 拖动屏幕角色跟随移动；点「冲刺」加速 + 粒子拖尾。
- [ ] 吞噬比自身小的鱼 → 变大、加分、连击提示。
- [ ] 被更大的鱼咬到 → 掉命、闪烁无敌，3 条命用尽 → 结算。
- [ ] 分数 / 最高纪录计算正确，结算页显示得分与「新纪录」。

## 5. 激励视频广告（复活）
- [ ] 单机模式结算页出现「看广告复活」金色按钮。
- [ ] 点击拉起激励视频；**看完** → 复活成功（1 条命 + 短暂无敌），继续对局。
- [ ] **中途关闭**视频 → 提示「广告暂不可用」，不复活。
- [ ] 无广告位 ID 或广告加载失败 → 提示兜底文案，**不崩溃、不卡死**。
- [ ] 双人模式结算页不显示复活按钮。

## 6. 分享
- [ ] 结算页「分享游戏」按钮可拉起分享；分享卡片标题为「开局捏鱼，吞遍深海——来一起当海洋之王！」。
- [ ] 右上角「···」菜单可分享（`showShareMenu` 已开启），标题/参数正确。
- [ ] 通过分享进入带 `from=share` 参数，游戏能正常打开（不因参数崩溃）。

## 7. 暂停 / 结算 / 再来一局
- [ ] 对局中「暂停」→ 继续 / 返回菜单 正常。
- [ ] 结算页「再来一局」重新开局，无残留粒子/鱼实体错乱。
- [ ] 连续打 5 局以上，无内存上涨、无越来越卡。

## 8. 切后台 / 存档（关键）
- [ ] 对局中切后台再回来 → 游戏状态不丢（或正确暂停）。
- [ ] 解锁皮肤 / 获得碎片后杀掉小程序 → 重新打开进度保留。
- [ ] 改昵称 / DIY 保存后重开 → 数据保留。

## 9. 云端存档（若已部署云函数）
- [ ] 未部署云函数时：游戏可正常玩，仅本地存档，不报错。
- [ ] 部署 `save` 云函数 + `player_saves` 集合后：换设备登录，进度可同步拉取。

## 10. 性能 / 适配（多机型）
- [ ] 竖屏显示正确，不同分辨率（720/1080/刘海屏）UI 不溢出、不重叠。
- [ ] 低端机对局帧率 ≥ 30fps（工程内置 FPS 自动降档，画质自动下调）。
- [ ] 长对局（10 分钟）无卡顿、无发热异常、无闪退。

## 上线前三项硬门槛（平台侧）
- [ ] 真实 AppID 已填入 `project.config.json`（非 `tt_` 占位）。
- [ ] 游戏备案已完成。
- [ ] 图标 / 截图 / 名称 / 简介 / 类目已在开放平台提交。
